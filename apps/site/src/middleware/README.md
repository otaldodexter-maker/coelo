# Middleware

Contexto reservado para documentar e apoiar middleware do site. Em Astro,
middleware real deve nascer como `src/middleware.ts` quando houver uma
necessidade concreta, como headers, redirects ou contexto por request.

No inicio, o site publico deve evitar middleware se paginas estaticas forem
suficientes.
