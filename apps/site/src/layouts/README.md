# Layouts

Cascas compartilhadas de pagina. Um layout define estrutura comum como
`html`, `head`, header, footer, slots de conteudo e metadados base.

Exemplos futuros:

- `MarketingLayout.astro`
- `ContentLayout.astro`
- `LegalLayout.astro`

Layouts devem compor componentes, nao carregar logica de produto privado.
