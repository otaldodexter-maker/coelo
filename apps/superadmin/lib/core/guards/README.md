# Guards

Equivalente Flutter do conceito de middleware de rota. Guards podem decidir
se uma tela deve abrir com base em sessao, papel, escopo ou contexto ativo.

Importante: guards melhoram UX, mas nao substituem autorizacao server-side,
RLS ou auditoria.
