# Briefing e checkpoints de revisão

Este arquivo recompõe o destino ausente do índice a partir das regras vigentes.
Não representa recuperação de um briefing histórico nem aprovação de novo lote.

Ao preparar um prompt de revisão, registrar objetivo, apps e famílias visuais,
telas/actions, pendências conhecidas, incluído/fora, ordem, parada e evidências.
Usar o [runbook de revisão](weekly-superadmin-ui-review.md) para o lote pertinente.
Preservar autorizações já dadas. Preparar um prompt não inicia sua execução.

Em lote autorizado, cada checkpoint informa arquivos afetados, verificações,
primeiro gate aberto e trabalho restante. Trabalho paralelo, commit e servidor
local dependem do pedido e da necessidade concreta; não são condições universais
para corrigir uma skill. Não declarar arquivos liberados enquanto houver escrita
concorrente. Só citar commit ou URL de preview que realmente existam.

Instruções antigas do índice sobre commit, três horas, múltiplos servidores ou
sequência fixa não substituem o recorte e a ordem explicitamente dados pelo Owner.
