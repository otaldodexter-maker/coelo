# Brand Assets

Assets oficiais da marca Coelo.

- `logos/svg/`: SVGs prontos para uso.
- `logos/png/`: PNGs prontos para uso.
- `fonts/nunito-sans/`: fonte Nunito Sans extraida do pacote oficial.
- `source/logo/`: arquivos fonte/editaveis e formatos originais.
- `source/fonts/`: pacote original da fonte.

Consulte `docs/source/assets-inventory.md`, `docs/design/design-system.md` e `docs/product/brand-history.md` antes de usar ou alterar assets.
