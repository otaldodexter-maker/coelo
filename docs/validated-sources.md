# Fontes externas validadas

Estas fontes foram usadas apenas para validar boas praticas atuais. Elas nao sobrescrevem a visao dos documentos oficiais do Coelo.

| Tema | Fonte | Uso na fundacao |
| --- | --- | --- |
| Astro | [Astro docs](https://docs.astro.build/en/concepts/why-astro/) | Validacao do site publico em Astro, foco em conteudo, performance e SEO. |
| Flutter | [Flutter app architecture](https://docs.flutter.dev/app-architecture/guide) | Validacao de separacao de camadas, testabilidade e estrutura de apps Flutter. |
| Supabase RLS | [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) | Validacao da estrategia de isolamento por tenant, policies e testes cruzados. |
| Supabase Storage | [Supabase Storage access control](https://supabase.com/docs/guides/storage/security/access-control) | Referencia comparativa para controle de acesso de midia, sem alterar a decisao de R2. |
| Cloudflare R2 | [Cloudflare R2 presigned URLs](https://developers.cloudflare.com/r2/api/s3/presigned-urls/) | Validacao do spike de URLs temporarias para midia privada em R2. |
| Acessibilidade | [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Referencia de acessibilidade para design system, UI core e criterios futuros. |
