# Fontes Oficiais

Esta pasta preserva as fontes oficiais usadas para gerar os Markdown derivados em `docs/`.

- `originals/docx/`: DOCX oficiais copiados sem alteracao intencional.
- `originals/assets/`: pacotes de assets originais quando aplicavel.
- `assets-inventory.md`: inventario dos assets de marca copiados para `assets/brand/`.

Os Markdown derivados sao convenientes para leitura e SDD, mas a fonte normativa continua sendo o conjunto oficial preservado aqui e as decisoes aprovadas em `decisions/`.
