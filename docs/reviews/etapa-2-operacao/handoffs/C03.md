Erros reutilizam os códigos normalizados das gateways v2, inclusive `SAI_CONCURRENT_CHANGE`, `ACTIVITY_INVALID_REFERENCE`, `ACTIVITY_NOT_FOUND` e negações `SAI_*`.
- Orquestração transacional: reutiliza `create/update`, `set_units`, `set_groups`, `set_participants`, `set_professionals`, `set_permissions` e, quando solicitado, `publish`. Cada capacidade é reautorizada antes do replay e novamente pelo comando filho. Qualquer envelope filho de erro é elevado dentro do sub-bloco; o catch externo reverte definição, vínculos, auditorias e recibos filhos da tentativa antes de devolver a negativa.

Repetição idêntica retorna o mesmo resultado com `replayed=true`; mudança apenas de payload ou intenção com o mesmo request retorna `SAI_CONCURRENT_CHANGE`; edição obsoleta é negada.
