C · Híbrido enxuto — recomendado

Compartilha shell, toolbar, tabela, filtros e estados; cada módulo adiciona apenas o bloco necessário, como etapas de importação ou prévia do aviso.

Por que recomendo C

  • Reutiliza o padrão aprovado de Instituições.
  • Preserva identidade comum sem forçar telas diferentes a parecerem iguais.
  • É a menor base útil para evoluir Admin e Principal depois.

Limite consciente

  • Não cria um dashboard completo por módulo.
  • Os dados e eventos reiniciam ao recarregar o protótipo.
